Perfect Numbers

A Python project for generating and exploring known perfect numbers.

What is a Perfect Number?

A perfect number is a positive integer equal to the sum of its proper positive divisors.

For example:

6

The proper divisors of 6 are:

1 + 2 + 3 = 6

Features

* Generate known perfect numbers
* Generate extremely large perfect numbers locally
* Explore the relationship between perfect numbers and Mersenne primes
* Verify perfect-number candidates
* Continue adding new verified discoveries

Requirements

* Python 3.12 or newer
* A computer with enough RAM and storage for very large numbers

How to Use

Clone or download this repository.

Run: perfect_numbers.py

```
bash
python 
```

Follow the instructions shown by the program.

The program generates the requested perfect number directly on your computer, so enormous numbers do not need to be stored in this GitHub repository.
Known Perfect Numbers

There are currently 52 known even perfect numbers.

The project uses the known Mersenne-prime exponents to generate them.
Future Discoveries

If a new perfect number is discovered and independently verified, it can be added to the project as:

* #53
* #54
* #55
* and so on.

A computational candidate should be independently verified before being described as a new perfect number.
